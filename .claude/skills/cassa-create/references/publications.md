# Publications page — ADS fetch, inclusion & IUB-share rules

Reference for the **cassa-create** skill. Read this before touching `/research/publications` (`src/pages/research/publications.astro`). These inclusion choices are **locked in with the user** — keep them consistent if the fetch/scoring is ever rebuilt or moved to a collection.

**Publications** (`/research/publications`) fetches CASSA papers from the **NASA ADS API at build time** — token in `.env` as `ADS_API_TOKEN` (already configured). Rebuild to refresh; renders stats + a full sortable list (sorted by IUB share / citations / year — no separate "most-cited" section; citation-sort makes it redundant). No token ⇒ a graceful SciXplorer fallback. `.env` is gitignored. **Corpus = the ADS affiliation search `aff:"Center for Astronomy, Space Science and Astrophysics"` ∪ the curated public ADS library `znTrvN1iRXOBQvd17VhYmA`**, deduped by bibcode. Do **not** broaden the *search* to `aff:"Independent University, Bangladesh"` — that pulls the whole university's ~700 non-astronomy papers (biomedical, EEE, CS); IUB-vs-CASSA matching is applied *within* this corpus only.

**Paper-inclusion + IUB-share rules (authoritative — locked in with the user):**
- **Count only journal + conference papers:** keep `doctype ∈ {article, inproceedings, proceedings}`; drop software deposits (Zenodo `zndo`), errata, abstracts, eprints, datasets — page-wide (stats, charts, and the list). (This is why the DOLPHIN *article* shows but its Zenodo *software* twin and the CSP *erratum* don't.)
- **Every paper carries an IUB share ∈ [0,1]** — the Nature-Index *Share* (fractional authorship) additionally weighted by **author primacy × affiliation primacy** (harmonic):  `S = Σ over IUB authors i of (1/rᵢ)/H_A · (1/kᵢ)/H_nᵢ`, where `rᵢ` = byline position, `A` = author count, `kᵢ` = IUB's rank in author *i*'s affiliation list, `nᵢ` = that author's affiliation count, `Hₙ` = nth harmonic number. 1 ⇒ all-IUB byline with IUB leading; 0 ⇒ no IUB author. Rendered as a badge beside **citations** + **year**; the list **sorts by IUB share (default) → citations → year**. The formula is documented in a build-time comment block and a user-facing footnote on the page.
- **"IUB" = the institution, not just CASSA-named:** match any affiliation naming *Independent University, Bangladesh* (incl. the full CASSA centre string). Other Bangladeshi institutions (SUST, Copernicus Astronomical Memorial of SUST, BUET, Rajshahi/Army UET, …) are **not** counted.
- **`aff`-parsing gotchas:** HTML-decode `&amp;`→`&` **before** splitting an author's `aff` on `;` (the `;` inside `&amp;` corrupts the split, inflating affiliation counts); match IUB on the anchor `"Center for Astronomy, Space Science"` **or** (`"Independent University"` + `"Bangladesh"`) co-occurring in one `;`-segment — tolerant of the Oxford comma (`"Space Science, and Astrophysics"`) and address word-order (`"…University, Dhaka, 1229, Bangladesh"`). The interactive sort control must be `<script is:inline>` (a hoisted bare `<script>` in page slot content is dropped).
